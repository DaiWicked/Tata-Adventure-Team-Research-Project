## 体积去哪了

```
aa/Android/inpackage_aa_1.lpak   236.4 MB   ← Addressables 内置美术资源（UnityFS，加密）
pgame.pkg                         19.5 MB   ← 游戏 Lua 脚本 + 动画/特效/英雄定义（加密载荷）
nedata.db                         12.9 MB   ← 数值/配置表（非明文 SQLite）
bin/Data/Managed/Metadata/global-metadata.dat  10.0 MB  ← IL2CPP 元数据（HTPX 加密）
```

结论：**342 MB 里真正决定「玩法与数值」的只有 30 MB 左右**，其余是美术。想研究逻辑，目标是
`pgame.pkg`（Lua）与 `nedata.db`（数值表），而不是 `res/` 里那 1090 个图标。

## 权限与组件

高危/值得注意的申请：

- `REQUEST_INSTALL_PACKAGES`（自更新安装）、`WRITE_EXTERNAL_STORAGE`/`READ_EXTERNAL_STORAGE`（maxSdk 32）、`CAMERA`（扫码/AR guess）、`RECEIVE_BOOT_COMPLETED`、`FOREGROUND_SERVICE`、`POST_NOTIFICATIONS`（推送）、`AD_ID`（广告标识）。
- 没有 `MOUNT_UNMOUNT_FILESYSTEMS`、`BIND_ACCESSIBILITY_SERVICE` 这类明显敏感项。

三方 SDK（从 so 与 assets 判断）：网易易盾（`libNetHTProtect`、`libnesec`、`libcheck`）、
莉莉丝 Park/PSP（`libparkcrypto`、`park/index.html`）、火山引擎 AppLog/Keva（`libkeva`、
`libvolc_log`）、CrashSight（`libCrashSight`、`libhtpcrash`）、微信（`libweibosdkcore`、
`motion/libxt*.so`）、华为 HMS/AGC、广点通 GDT（`gbsdk.plugin.*.apk`）、
Adjust（`libsigner.so` 里 `Java_com_adjust_sdk_sig_NativeLibHelper_nSign`）、
移动安全联盟 OAID（`libmsaoaidsec`）、AVPro（`libAVProMovieCaptureNative`）、
hdiffpatch（`libhdiffpatch`，热更新差分）。

## 值得注意的「设计痕迹」

- `assets/aa/Android/inpackage_aa_1.lpak` 的头是 `UnityFS`，但版本串被改成 `5.x.x` / `0.0.0`：
  典型的 **AssetBundle 加密改写**（详见 03 篇，UnityPy 直接判定为 Unity 官方
  `ArchiveStorageManager` 加密）。
- `global-metadata.dat` 头是 `HTPX`（网易易盾自定义容器），不是 IL2CPP 原生 magic
  `0xFAB11BAF` —— 说明**元数据被壳层整体加密**，这也是为什么在 `libil2cpp.so` 里搜不到
  任何业务类名。
- `assets/lilith_sdk_modules/*` 全是 0 字节：这是 SDK 的「按需加载」标记文件，
  说明支付/社区等功能是按模块动态加载的，不是编译进主 dex。
