## 8 字节块重复统计（会话内联跑出，未单独落盘，命令见下）

```bash
py -3 - <<'EOF'
import collections
for path, skip in [('unpack/assets/pgame.pkg', 8),
                   ('unpack/assets/Config/LanguageDbZH.luae', 8),
                   ('unpack/assets/nedata.db', 0)]:
    d = open(path, 'rb').read()[skip:]
    pos = collections.defaultdict(list)
    for i in range(0, len(d) - 8, 8):
        pos[d[i:i+8]].append(i)
    dup = {k: v for k, v in pos.items() if len(v) > 1}
    n = len(d) // 8
    print(path, 'blocks', n, 'dupgroups', len(dup),
          'dupblocks', sum(len(v) for v in dup.values()),
          'random_expect', '%.2e' % (n*n/2/2**64))
EOF
```

实测输出（关键三行）：

```
pgame.pkg                    blocks 2434020 dupgroups 123134 dupblocks 723922 random_expect 1.61e-07
LanguageDbZH.luae            blocks   52912 dupgroups    104 dupblocks    286 random_expect 7.59e-11
nedata.db                    blocks 1623612 dupgroups      0 dupblocks      0 random_expect 7.15e-08
```
